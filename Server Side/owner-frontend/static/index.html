Persona Groups

Strategy: Each user is scored from a 30-day rolling window of EnergyRanking rows (efficiency 50% · goal adherence 30% · decision response 20%). Users with < 2 ranking days or no readings in the last 14 days fall to Disengaged. The remaining users are sorted by combined score and assigned by community percentile: top 20% → Eco Champion · 55–79th percentile with improving trend → Active Improver · 25–79th → Steady User · bottom 25% → High Consumer.
